Usage

Send the token in the Authorization header. Token-holding requests bypass the SAML login entirely.

curl -H "Authorization: Bearer pfk_..." \
  -H "Content-Type: application/json" \
  -d '{"terms": ["aa:bb:cc:dd:ee:ff"]}' \
  https://<this-host>/api/search
